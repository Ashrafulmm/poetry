## Introduction to OLS

Ordinary Least Squares (OLS) is a statistical method that estimates the parameters in a linear regression model.

<Callout type="warning" title="Important Formula">
  Make sure to memorize the OLS estimator derivation for the midterm.
</Callout>

### Key Assumptions

1. Linearity in parameters
2. Random sampling
3. No perfect collinearity
