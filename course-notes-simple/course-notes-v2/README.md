# Course Notes Hub

Personal bachelor's course notes website.

## How to Add a Lecture

1. Create a new `.mdx` file in `src/pages/[course-name]/`
2. Copy the frontmatter template from any existing lecture
3. Write your notes in Markdown below the frontmatter
4. Push to GitHub — Vercel auto-deploys
